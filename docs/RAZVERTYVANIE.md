# Развёртывание на другом устройстве

Статический сайт: ни сборки, ни сервера, ни ключей.

## Что понадобится

- Браузер. Для публикации — аккаунт GitHub `sasha057AI` с доступом к репозиторию
  `website_fitbest`.

## Шаги

1. **Получить код.** `git clone https://github.com/sasha057AI/website_fitbest.git`;
   без GitHub — из бандла с флешки: `git clone <файл>.bundle "Сайт по стульям"`.
2. **Открыть локально.** Двойной клик по `index.html`. Если браузер блокирует
   скрипт по `file://` — любой статический сервер, например
   `python -m http.server` в корне проекта.
3. **Опубликовать.** `git push` в `main`; GitHub Pages (Settings → Pages → ветка
   `main`, корень) отдаёт `https://sasha057ai.github.io/website_fitbest/`.
   Пуш только с подтверждения заказчика.
4. **Проверить.** Каталог рисуется (10 товаров), модалка заказа открывается,
   `robots.txt`, `sitemap.xml`, `llms.txt` отдаются.

## Откуда берутся данные

Товары и цены — массив `products` в `js/main.js`, тот же перечень в `ld+json`
(`index.html`) и `llms.txt`. Источник правды по ассортименту и ценам — проект
`D:\FitBest_Claude_code`. Фото товаров — `assets/products/`.

Ничего: сайт самодостаточен. Без Claude Code остаются ручные правки по README.
