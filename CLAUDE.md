# Сайт по стульям (FitBest) — правила проекта

Статический одностраничный сайт-лендинг магазина FitBest: кресла и стулья для
салонов красоты. HTML + CSS + ванильный JS, без сборщиков. Опубликован как
GitHub Pages: https://sasha057ai.github.io/website_fitbest/. Остальной контур
FitBest (экономика, маркетплейсы) — в соседнем проекте `D:\FitBest_Claude_code`.

## Карта проекта

| Нужно | Открой |
|---|---|
| Состояние, что дальше | `PROGRESS.md` («Быстрый старт») |
| Как открыть, как править товары, цвета, контакты | `README.md` |
| Страница целиком (шапка, каталог, «О нас», футер, модалка) | `index.html` |

| Опубликовать / поднять локально | `docs/RAZVERTYVANIE.md` |

## Правила

- **Данные о товарах, ценах и контактах дублируются в трёх местах:** `js/main.js`
  (отображение), блоки `ld+json` в `index.html` и `llms.txt` (поиск). Менять
  всегда во всех трёх, иначе поисковики покажут старые цены.
- При смене адреса сайта обновить `canonical`, Open Graph, `sitemap.xml`,
  `robots.txt`, `llms.txt`.
- Форма заявки пока не отправляет данные (заглушка «Спасибо») — не обещать
  заказчику, что заявки приходят. Подключение — Formspree или аналог, см. README.
- Сборщиков и фреймворков не добавлять: сайт должен открываться двойным кликом.
- Дизайн-правки — через скилл `impeccable`.
